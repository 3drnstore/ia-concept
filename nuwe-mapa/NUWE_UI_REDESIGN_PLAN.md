# Nuwe Mapa — UI redesign

Nova direção visual inspirada no MAPS.ME, sem copiar ativos/branding. OsmAnd permanece apenas como engine. Interface visível passa a ser Nuwe.

Requisitos principais:
- sem barra inferior persistente;
- launcher circular central;
- bottom sheet expansível;
- controles próprios: camadas, régua, zoom, posição, 2D/3D, bússola/orientação;
- somente perfis Carro, Bike e Trilha;
- sem Cloud, compras e perfis extras na UI;
- settings própria;
- manter o ícone Nuwe já criado anteriormente;
- não renderizar widgets visuais herdados do OsmAnd.
